## 🚀 How to Start Using

### Option 1: Simple Start
```
Double-click: Valndor.bat
```

### Option 2: With Prompt
```
Double-click: start_server.bat
Press: Y to hide, N to show
```

### Option 3: Command Line
```
python server.py
```

### Connect
1. Server displays local IP (e.g., `http://192.168.1.100:5000`)
2. Open that address in browser on same WiFi network
3. See remote screen and control buttons
4. Start controlling!
