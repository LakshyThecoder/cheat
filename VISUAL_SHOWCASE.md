## 🎭 Animation Effects

### Hover Effects
```
Button Hover:      Transform: translateY(-4px)
                   Shadow: 0 8px 25px rgba(0,0,0,0.2)
                   Effect: Lifts up, increases shadow

Section Hover:     Transform: translateY(-2px)
                   Shadow: 0 8px 30px rgba(124,58,237,0.2)
                   Effect: Subtle lift, enhanced shadow

Input Focus:       Border: #6d28d9 (darker)
                   Shadow: 0 0 20px rgba(124,58,237,0.3)
                   Background: #f8f5ff (light purple)
                   Effect: Purple glow, focus highlight

### Load Animations
```
Pulse Loading:     @keyframes pulse
                   ├─ 0%: scale(1), opacity(1)
                   ├─ 50%: scale(1.2), opacity(0.5)
                   └─ 100%: scale(1), opacity(1)

                   ├─ from: translateY(10px), opacity(0)
                   └─ to: translateY(0), opacity(1)
